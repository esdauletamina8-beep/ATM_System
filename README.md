# Банкомат жүйесі (ATM System)

## 1. Студент туралы ақпарат

- **Студенттің ТАӘ:** Есдаулет Амина
- **Нұсқа:** 1-нұсқа
- **Жоба тақырыбы:** Банкомат жүйесі

## 2. Жобаның сипаттамасы

Бұл жоба C++ бағдарламалау тілі және объектіге бағытталған бағдарламалау (ООП) негізінде жасалған банкомат жүйесі болып табылады.

Жүйе клиенттерді, банк шоттарын, банк карталарын, қаржылық операцияларды және банкоматтың жұмысын басқарады.

## 3. Жүйенің негізгі мүмкіндіктері

- Клиент қосу
- Банк шотын құру
- Шот балансын тексеру
- Ақша салу
- Ақша шешу
- PIN-кодты тексеру
- Банк картасын бұғаттау
- Операциялар тарихын көру
- Жинақ шотына пайыз есептеу

## 4. Қолданылған кластар

1. Client – Клиент
2. Account – Банк шоты
3. SavingsAccount – Жинақ шоты
4. BankCard – Банк картасы
5. Transaction – Қаржылық операция
6. ATM – Банкомат

## 5. Қолданылған ООП принциптері

- Инкапсуляция
- Мұрагерлік
- Композиция
- Агрегация
- Статикалық мүшелер
- Дос функция
- Дос класс
- Кірістірілген класс
- Объектілер жиымы

## 6. Қолданылған технологиялар

- C++ бағдарламалау тілі
- GitHub платформасы
